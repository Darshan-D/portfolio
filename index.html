YouTube Music still doesn't do crossfade, and I wanted to understand why it's actually hard. So I built the engine myself: two "AVAudioEngine" decks that quietly swap places mid-track, each with its own gain automation, handing off sample-accurately. Offline-First

MatchMate

Get Code

I wanted to see how far I could push an offline-first architecture in a small app. MatchMate is a Tinder-style swipe deck where an actor-based repository is the single source of truth, broadcasting changes over an "AsyncStream" so every screen stays in sync in real time. Once a page has cached it keeps working in Airplane Mode, and SwiftData persistence runs entirely off the main thread.
